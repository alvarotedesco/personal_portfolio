# Personal Portfolio

> Personal portfolio developed to present my professional profile, technical skills, projects, and experience in software development.

---

## 🇧🇷 Sobre o projeto

Este projeto consiste no desenvolvimento do meu portfólio pessoal, criado para apresentar meu perfil profissional, conhecimentos técnicos, projetos e experiências na área de desenvolvimento de software.

O projeto também é utilizado como um espaço para aplicar e aprimorar conceitos de desenvolvimento web, organização de código, responsividade, acessibilidade e boas práticas de desenvolvimento.

## 🛠️ Tecnologias

* HTML5
* CSS3
* JavaScript
* jQuery

## 📚 Práticas aplicadas

Durante o desenvolvimento do projeto, são aplicados conceitos e boas práticas de desenvolvimento web, incluindo:

* HTML5 semântico;
* CSS3 e organização modular de estilos;
* JavaScript moderno;
* Design responsivo e abordagem mobile-first;
* Organização e reutilização de componentes;
* Acessibilidade utilizando recursos nativos do HTML e atributos ARIA;
* Separação de responsabilidades entre estrutura, apresentação e comportamento;
* Controle de versão utilizando Git e GitHub.

## 🎯 Objetivos

* Apresentar meu perfil profissional;
* Demonstrar conhecimentos em desenvolvimento web;
* Aplicar boas práticas de organização e manutenção de código;
* Desenvolver uma interface responsiva e acessível;
* Aprimorar conhecimentos por meio do desenvolvimento contínuo do projeto;
* Utilizar o projeto como parte do meu portfólio profissional.
